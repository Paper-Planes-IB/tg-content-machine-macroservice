# Apps Script

`Code.template.gs` - шаблон для рабочего Google Apps Script.

В репозитории не хранить:

- реальные значения `CFG.auth`;
- закрытые URL с доступами;
- токены;
- выгрузки с персональными данными.

Перед установкой в рабочую таблицу технический владелец должен заполнить конфигурацию в защищенном контуре и проверить права доступа.
