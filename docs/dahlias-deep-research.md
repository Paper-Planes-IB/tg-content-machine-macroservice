# TG: deep research по георгинам и обновление контент-машины

Дата: 2026-08-25  
Тема: акция на букеты из георгин  
Статус: исследовательский пакет и предложение обновления  
Граница: цены, сроки акции, наличие, филиалы, доставка и фактические результаты публикаций подтверждаются только источниками TG.

## 1. Промпт для deep research

```text
Задача: провести исследование для контент-машины цветочного бренда Toshkent Gullari в Ташкенте. Тестовый товарный повод: акция на букеты из георгин.

Нужно собрать методическую и рыночную базу, из которой SMM-агент сможет генерировать темы, сценарии, раскадровки и проверки. Рекламный текст на этом шаге не нужен.

Контекст:
- бренд продает цветы, букеты, растения, подарки, обучение и свадебную флористику;
- основной операционный интерфейс - Google Sheets с контент-планом;
- форматы: Instagram Reels, Stories, лента, видео для продвижения с ценами, Telegram;
- команда обычно снимает: говорящую голову, атмосферное видео с моделью, продуктовые ролики, ролики с ценой;
- нужна человеческая, конкретная коммуникация без общих фраз про красоту;
- нельзя придумывать цену, наличие, филиал, срок акции, доставку и результаты продаж.

Исследовать:
1. Тренды цветочного рынка 2025-2026: повседневная покупка, self-purchase, home styling, подарки, мужская аудитория, Gen Z, экологичность, персонализация, соцсети.
2. Тренды флористического дизайна 2026: монобукеты, монохром, крупная форма, архитектурность, движение, фактура, теплые осенние палитры, камерные букеты, цветы как часть образа.
3. Георгины как товар: сезонность, визуальная сила, оттенки, размеры, стойкость, уход, ограничения, честные формулировки.
4. Как продавать акцию на георгины в Instagram и Telegram: контентные углы, первые кадры, сценарии, тексты, вовлечение, путь к заказу.
5. Как строить ролики для продвижения: первые 2-3 секунды, вертикальный формат, безопасные зоны, субтитры, цена, следующий шаг.
6. Что должно попасть в таблицу контент-плана: новые рубрики, сигналы, метрики, стоп-условия, поля для проверки.

Выход:
- 10-15 проверенных выводов с источниками;
- карта трендов: тренд -> что это значит для TG -> как использовать в теме;
- 12 контентных углов по георгинам;
- обновление для таблицы контент-плана;
- обновление для скиллов tg-content-planner, tg-storyboard, tg-content-qa;
- список стоп-формулировок и честных замен;
- список фактов, которые должен подтвердить клиент.
```

## 2. Что показало исследование

### 2.1. Цветы все чаще покупают вне больших праздников

Внешние обзоры сходятся в одном: цветы перестают быть только подарком на дату. Растет роль цветов для дома, самопокупки, настроения, рабочего пространства и маленьких повседневных поводов. Для TG это означает, что акция на георгины должна иметь две линии: подарок и покупка для себя.

Обновление для тем:

- "георгины для дома";
- "букет на рабочий стол";
- "цвет без большого повода";
- "яркий букет на эту неделю".

### 2.2. Молодая аудитория покупает цветы как способ самовыражения

Исследование Floral Marketing Fund по Gen Z связывает цветы с эмоциональным состоянием, самовыражением и повседневной связью между людьми. TG не нужно копировать американскую лексику. Для контента это дает более прикладную рамку: "букет как часть образа", "цветы для своего пространства", "подарок без тяжелого повода".

Обновление для тем:

- "георгины под образ";
- "букет, который хочется поставить дома";
- "цветы как жест внимания без повода";
- "что выбрать, если хочется яркий цвет сегодня".

### 2.3. Визуальная торговля стала витриной

Отраслевые источники по флористике и рекламе сходятся: Instagram, Pinterest, Reels и мобильные витрины становятся точкой первого контакта. Для TG первый кадр должен выполнять работу продавца: человек видит товар, цену или ситуацию покупки до того, как читает подпись.

Обновление для правил:

- первый кадр: букет, цена, человек или действие;
- никакой заставки с логотипом;
- титры не закрывают цветок;
- цена в ролике для продвижения должна читаться на телефоне;
- звук полезен, но субтитры обязательны.

### 2.4. Георгины подходят для hero-shot

Георгины сильны крупной формой, фактурой лепестков, оттенками и выразительным силуэтом. Это делает их хорошим товаром для короткого ролика: не надо долго объяснять, почему букет заметен.

Обновление для форматов:

- крупный цветок в первые 0,5 секунды;
- макро-фактура лепестков;
- букет в руках человека;
- сравнение трех оттенков;
- один букет в интерьере.

### 2.5. Георгины требуют честной коммуникации по стойкости

Источники по уходу за срезанными цветами и георгинами показывают, что георгины красивы, но чувствительны. Их нельзя продавать как самый стойкий цветок. Можно продавать как выразительный сезонный букет и давать простой уход: чистая ваза, свежая вода, подрезка стеблей, прохлада, отсутствие прямого солнца.

Обновление для QA:

- не обещать долгую стойкость без источника TG;
- уход давать как заботу после покупки;
- крупные сорта показывать через визуальный эффект, а не через обещание срока жизни.

### 2.6. В 2026 растет спрос на персонализацию

Покупателю нужен выбор под человека, бюджет, интерьер, повод, оттенок и формат доставки. Акция должна быть разложена на 3-4 понятные ветки выбора.

Обновление для тем:

- "3 букета из георгин под разный бюджет";
- "нежный, яркий, объемный";
- "для учителя, для дома, для свидания";
- "что написать менеджеру, чтобы быстро подобрать букет".

### 2.7. Монобукеты и моноцвет работают как простой выбор

Свадебные и флористические тренды 2026 часто называют монобукеты, монохром, крупный фокусный цветок и более архитектурные формы. Для TG это хорошо ложится на георгины: один цветок становится главным объектом кадра.

Обновление для библиотеки:

- монобукет из георгин;
- моноцветная подборка;
- один крупный акцент;
- сравнение "один цвет" и "несколько оттенков".

### 2.8. Осенние палитры дают готовую визуальную систему

Для георгин особенно сильны теплые оттенки: бордо, сливовый, ржаво-оранжевый, кремовый, розовый, винный. Они подходят для осени, учительских подарков, домашних букетов и атмосферных роликов.

Обновление для съемки:

- снимать по цветовым группам;
- не смешивать все оттенки в один ролик;
- дать отдельные темы: кремовые, бордовые, яркие, нежные.

### 2.9. Ролик для продвижения должен быть проще органического

Для продвижения нужен быстрый ответ на покупательский вопрос: что за букет, сколько стоит, где заказать, до какого числа акция. Meta рекомендует вертикальный формат, безопасные зоны, понятное сообщение и качественный звук. Практические разборы Reels-рекламы также сходятся на первых 2-3 секундах, субтитрах и ролике, похожем на обычную публикацию.

Обновление для роликов:

- первый кадр: товар + цена;
- второй кадр: размер и цвет;
- третий кадр: повод;
- четвертый кадр: заказ;
- субтитры в безопасной зоне.

### 2.10. Тренды не заменяют внутренние сигналы

Внешний тренд нужен как слой для качества темы. Он не должен решать, что публиковать вместо реальных данных TG. Главный порядок: наличие, акция, маржинальность/норма прибыли, задача продаж, затем трендовый угол.

## 4. Новые контентные углы для георгин

1. Георгины как крупный сезонный цветок.
2. Букет для дома без большого повода.
3. Букет как часть образа человека.
4. Три оттенка под разное настроение.
5. Три размера под разный бюджет.
6. Монобукет из одного цветка.
7. Бордовые / кремовые / яркие георгины отдельными сериями.
8. Георгины для учителя или наставника.
9. Георгины для рабочего стола.
10. Букет, который хорошо смотрится в руках.
11. Уход за георгинами после покупки.
12. Быстрый подбор через три вопроса менеджеру.
13. Подарок, который не требует долгого выбора.
14. Сезонная акция до конкретной даты.
15. Фото до и после: букет в витрине и букет в руках.

## 6. Обновление для скиллов

### tg-content-planner

Добавить в правила выбора темы:

- сначала проверять товарный факт и условия акции;
- затем выбирать один трендовый угол;
- не смешивать больше двух углов в одной теме;
- для акции обязательно требовать цену или статус "цену уточнить";
- для георгинов учитывать ограничение по стойкости и не обещать лишнего.

### tg-storyboard

Добавить в правила раскадровки:

- для георгинов обязательны крупный план лепестков и кадр букета в руках или интерьере;
- для продвижения с ценой первый кадр содержит товар и цену;
- для атмосферного ролика выбирать один цветовой сценарий;
- титры держать в безопасной зоне и не закрывать цветок.

### tg-content-qa

Добавить проверки:

- есть ли трендовый угол и не заменил ли он товарный факт;
- не обещана ли стойкость без основания;
- есть ли цена/срок для акции;
- не смешаны ли подарок, самопокупка, дом и учитель в одну тему;
- виден ли реальный товар в первом кадре.
