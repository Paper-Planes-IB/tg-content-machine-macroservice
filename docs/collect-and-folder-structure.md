# Collect и структура папок компании

Дата: 2026-08-29  
Статус: рабочая схема для макросервиса контент-плана

## 1. Роль collect

`Collect` - входной слой контент-машины. Он отвечает на вопрос: какие подтвержденные вводные можно использовать для контент-плана, съемки, текста и проверки.

Материалы из `Collect` дают агентам право:

- выбрать тему;
- связать тему с аккаунтом, аудиторией, товаром, календарем и сигналом;
- сформулировать первый кадр;
- назначить формат;
- передать задачу в съемку;
- проверить цену, наличие, срок акции и ограничения перед публикацией.

Если вводная не подтверждена, она идет в `10_Open_Questions`. В план она попадает только как вопрос или гипотеза.

## 2. Минимальные вводные для контент-плана

### Компания и направления

Нужны:

- список направлений: Flowers, Plants, Gourmet, Guul, School, Wedding, Nour, CEO / Mukhrim;
- роль каждого аккаунта;
- что продает направление;
- кто владелец направления;
- какие форматы допустимы;
- какие темы запрещены или требуют согласования.

Для папок это слой `01_Company_Context` и `02_Accounts_and_Directions`.

### Коммерческие вводные

Нужны:

- акции;
- приоритетные товары;
- цены;
- сроки действия;
- наличие;
- филиалы;
- доставка;
- товары с хорошей нормой прибыли;
- товары с просадкой;
- товары, которые надо распродать;
- товары, где нужен тест спроса.

Для папок это слой `04_Products_and_Offers`.

### Аудитории и сценарии покупки

Нужны:

- сегменты клиентов;
- поводы покупки;
- вопросы клиентов;
- возражения;
- подарочные сценарии;
- сценарии для дома;
- корпоративные сценарии;
- свадебные сценарии;
- родительские и школьные сценарии;
- постоянные покупатели.

Для папок это слой `03_Audiences`.

### Календарь

Нужны:

- праздники;
- локальные даты Узбекистана;
- сезонность цветов;
- школьные даты;
- свадебные сезоны;
- внутренние акции;
- даты запусков;
- даты, где нельзя перегружать команду съемкой.

Для папок это слой `05_Calendar`.

### Контентные правила

Нужны:

- рубрики;
- тональность;
- правила по текстам;
- правила по визуалу;
- правила по лицам в кадре;
- правила по ценам;
- правила по обещаниям;
- примеры удачных публикаций;
- примеры слабых публикаций;
- стоп-лист формулировок.

Для папок это слой `06_Content_Rules`.

### Маркетинговые сигналы

Нужны:

- топ публикаций;
- слабые публикации;
- охваты;
- сохранения;
- реакции;
- вопросы в сообщениях аккаунта;
- комментарии;
- результаты продвижения;
- конкурентные находки;
- повторяющиеся вопросы аудитории.

Для папок это слой `02_Signals`.

### Производственные вводные

Нужны:

- архив фото и видео;
- свежие съемки;
- доступные букеты и товары;
- модели;
- флористы;
- локации;
- реквизит;
- требования к монтажу;
- шаблоны обложек;
- готовые субтитры и титры.

Для папок это слой `08_Source_Media` внутри collect и общий слой `04_Production`.

### Фактические проверки

Нужны:

- кто подтверждает цену;
- кто подтверждает наличие;
- кто подтверждает срок акции;
- кто подтверждает доставку;
- кто подтверждает филиал;
- кто подтверждает итоговый текст;
- кто подтверждает публикацию.

Для папок это слой `09_Client_Approvals` и `10_Open_Questions`.

## 4. Связка с Google Sheets

Папки не дублируют таблицу. Таблица остается пультом.

Связка такая:

- `01_Collect` дает справочники и подтвержденные вводные;
- `02_Signals` дает основания для тем;
- `03_Planning` хранит месячные и недельные планы;
- `04_Production` хранит раскадровки и задания;
- `05_Ready` показывает, что можно публиковать;
- `06_Published` дает ссылки и факты публикации;
- `07_Analytics` возвращает результат;
- `08_Methodology` обновляет скиллы и правила;
- `09_Admin` держит доступы, роли и процесс.

Основные листы таблицы:

- `00_Пульт редактора` - ежедневная точка входа;
- `08_План недели` - рабочий слой планирования;
- `05_Сводный план` - общий реестр публикаций;
- `IG_*` - аккаунтные планы;
- `02_Сигналы` - основания;
- `03_Календарь года` - календарные поводы;
- `04_Аудитории` - сегменты;
- `06_Правила контента` - правила;
- `07_Банк идей` - идеи и механики.

## 5. Как агент использует collect

Перед генерацией темы агент проверяет:

1. Есть ли аккаунт и направление.
2. Есть ли подтвержденная акция, товар или повод.
3. Есть ли аудитория и сценарий покупки.
4. Есть ли календарное окно.
5. Есть ли сигнал или ручное основание.
6. Есть ли правило рубрики.
7. Есть ли источник фото или план съемки.
8. Есть ли факты, которые надо подтвердить человеком.

Если не хватает цены, срока акции, наличия, филиала или доставки, тема получает статус `Требует фактической проверки`.

## 6. Collect для темы георгинов

Для акции на букеты из георгинов нужны:

- направление: Flowers;
- товар: букеты из георгинов;
- условия акции: цена, срок, наличие, филиалы, доставка;
- аудитории: подарок, дом, учитель, сезонная покупка;
- календарное окно: сезон георгинов и ближайшие поводы;
- визуальные вводные: оттенки, размер букетов, упаковка, готовые фото и видео;
- съемочные вводные: модель, локация, флорист, букет в руках, крупные планы;
- форматы: говорящая голова, атмосферное видео, продуктовый ролик для ленты, ролик для продвижения с ценой;
- проверки: цена, срок акции, наличие, обещания по стойкости, корректность цветопередачи.

## 7. Правило для команды

Любой файл в collect должен отвечать хотя бы на один вопрос:

- что продаем;
- кому продаем;
- почему сейчас;
- чем подтверждено;
- как снять;
- кто согласовал;
- что проверить перед публикацией.

Если файл не отвечает ни на один вопрос, он идет в архив или в `10_Open_Questions` с коротким пояснением.
